## 💡 Resumo

Este projeto propõe uma solução para **otimizar a distribuição de vagas
em creches**, buscando reduzir o tempo de espera das famílias e melhorar
o aproveitamento das vagas disponíveis.

Atualmente, durante o processo de inscrição, cada criança pode
selecionar até **5 unidades de preferência**. Essas escolhas podem fazer
com que uma mesma criança permaneça simultaneamente posicionada em
diferentes filas enquanto aguarda uma convocação.

Nossa proposta **não altera a liberdade de escolha das famílias e não
substitui os critérios oficiais de classificação e vulnerabilidade já
existentes**.

A solução adiciona uma camada de otimização que considera:

-   Preferências das famílias
-   Classificação oficial
-   Vagas disponíveis

A partir dessas informações, o sistema busca analisar a distribuição de
forma mais ampla, identificando combinações que possam melhorar a
utilização das vagas e permitir que posições ocupadas em outras filas
sejam liberadas mais rapidamente.

O objetivo é contribuir para:

-   redução de vagas ociosas;
-   redução do tempo entre inscrição e convocação;
-   melhor aproveitamento das vagas disponíveis;
-   distribuição mais eficiente;
-   preservação das preferências das famílias e dos critérios oficiais
    de prioridade.

### Fluxo conceitual

``` text
Famílias realizam a inscrição
            ↓
Selecionam até 5 unidades
            ↓
Preferências das famílias
            +
Classificação oficial
            +
Vagas disponíveis
            ↓
Motor de otimização
            ↓
Distribuição sugerida
            ↓
Liberação das demais posições nas filas
            ↓
Próximas famílias avançam
```

A proposta é complementar o processo existente, utilizando tecnologia
para observar não apenas cada fila individualmente, mas o conjunto de
vagas, preferências e classificações.
