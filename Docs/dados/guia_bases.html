Guia das bases de dados

Mapeamento de todas as bases encontradas na pasta do projeto — origem, grão, colunas e observações de qualidade. Cobre 5 processos seletivos de creche (2021–2025), monitoramento mensal de vagas em unidades parceiras e públicas, malha territorial de microáreas e nascidos vivos por bairro.

⚠ Todos os dados de inscrição/classificação passaram por anonimização (aleatorização, generalização, supressão). Indicadores absolutos gerados a partir deles não representam a realidade — servem só para ilustrar dinâmicas do processo.
⚠
Armadilhas que já derrubaram análises nesta base:
  • Query A não vem filtrada por situacao — cancelamentos são 55% das linhas.
  • Valor gravado é "Cancelado na confirmacao", sem cedilha/til.
  • Query D (unidades) não tem cabeçalho — leia com header=None.
  • Régua de pontuação (Query C) mudou entre 2023→2024: só 3 das 13 perguntas sobreviveram.
  • Query B tem 4,36M linhas — não abre inteira no Excel (teto de 1.048.576 linhas).

Parceiras 2021–2025

OferecimentosEvagas/Parceiras20XX.xlsx

Consolidados mensais (enviados pelas CREs) de matrículas e vagas nas creches conveniadas/parceiras. Cada ano é um arquivo Excel com layout próprio — colunas e abas mudam ano a ano.

⚠
Cabeçalhos ocupam 2–4 linhas mescladas (grupamento etário na linha de cima, Turma/Aluno/Incluído/Vagas embaixo). Não dá para ler direto com header=0 — é preciso combinar linhas ou usar header=[0,1].

ArquivoAbasGrão / conteúdo

Parceiras2022.xlsxMAIO · QUADRO RESUMOMAIO = detalhe por unidade (inclui alunos incluídos por grupamento, redução de vagas por inclusão); QUADRO RESUMO = totais agregados por CRE

Parceiras2025.xlsxApoio · Endereços · MAIO -2025Layout mais enxuto: uma linha por unidade com Aluno/Incluído/Meta/Vagas por grupamento (BI, BII, MI, MII) e "Grupamentos autorizados"
Chaves de identificação da unidade (variam por ano)

CÓDIGO SGA / DESIGNAÇÃO — código interno da SME (4 dígitos, ex.: 1004, 1005). É o identificador mais estável entre anos e liga com as abas "Endereços" de 2024/2025.

INEP / CNPJ / SISEP — aparecem só a partir de 2023, únicos por creche parceira.

Grupamentos etários (colunas repetidas)

Berçário I (BI) · Berçário II (BII) · Maternal I (MI) · Maternal II (MII) — cada um com sub-métricas Turma/Aluno/Incluído(deficiência)/Vagas, variando conforme o layout do ano.
